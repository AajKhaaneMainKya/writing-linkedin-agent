# Skill: draft

## Purpose
Turn the research brief into a first-draft blog post of ~1000 words.
This is a rough draft — it will go through proofread, de-AIify, and validate next.
The goal here is to get the argument down, not to polish.

## Input
Read: `outputs/research/[latest]-research.md`
Read: `CLAUDE.md` for voice rules

## Ollama — how to call it for drafting

The draft is generated by calling Ollama with the research brief and voice rules
injected into the system prompt.

```python
import requests, os, json

OLLAMA_MODEL = os.environ.get("OLLAMA_MODEL", "mistral")
OLLAMA_URL = "http://localhost:11434/api/chat"

def check_ollama():
    try:
        requests.get("http://localhost:11434", timeout=3)
    except Exception:
        print("ERROR: Ollama is not running. Start it with: ollama serve")
        import sys; sys.exit(1)

def generate_draft(research_brief, voice_rules):
    system_prompt = f"""You are ghostwriting a blog post for Rahul.
Voice rules — follow these exactly:
{voice_rules}

Research brief:
{research_brief}

Write a ~1000 word blog post. Follow the structure in the draft skill exactly.
Do not add a preamble. Output only the article, starting with the title as # Heading.
"""
    resp = requests.post(OLLAMA_URL, json={
        "model": OLLAMA_MODEL,
        "messages": [{"role": "user", "content": system_prompt}],
        "stream": False
    }, timeout=120)
    resp.raise_for_status()
    return resp.json()["message"]["content"].strip()

check_ollama()
```

## Constraints from CLAUDE.md (always apply)
- No em dashes
- No AI-isms (see CLAUDE.md banned word list)
- First person where appropriate
- Short paragraphs — 3-4 lines max
- Opinions stated plainly, not hedged into oblivion
- Specific numbers over vague gestures

## Structure to follow

### Opening (100-150 words)
Do NOT start with a question. Do NOT start with "In recent years" or "The world is changing."
Start with a specific, concrete observation — a number, a moment, a contradiction.
The first sentence should make someone want to read the second.

### The core argument (200-250 words)
State what you actually think. Not what everyone agrees on — what the research revealed
that is non-obvious or undercovered.
Use one strong data point to anchor it.

### Supporting move 1 (150-200 words)
First layer of evidence or reasoning. Ground it in a source from the research brief.

### Supporting move 2 (150-200 words)
Second layer — ideally from a different angle (technical / commercial / political).
This is where the semiconductor / investment / strategy lens comes in depending on topic.

### Supporting move 3 or counterargument (150-200 words)
Either a third supporting point OR steelman the opposing view and knock it down.
The latter makes better reading.

### Closing (100-150 words)
No summary. No "in conclusion." End with:
- A forward-looking implication
- OR a question the piece leaves open (stated as a statement, not a question)
- OR the thing you'd do differently if you were running the company / fund / team
